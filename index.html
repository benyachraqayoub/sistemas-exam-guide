⚖️ TCP vs. UDP (Capa de Transporte)

          

            

              
                

                  Característica
                  TCP
                  UDP
                

              
              
                
Conexión previaSí (orientado a conexión)No (sin conexión)

                
Fiabilidad y ordenFiable, ordenado y con confirmacionesNo garantiza entrega ni orden

                
RetransmisiónReenvía si se pierden datosNo retransmite

                
Velocidad / UsoMás pesado · Webs, archivos, correoMás rápido y ligero · DNS, tiempo real

                
PuertosSí (0–65.535)Sí (0–65.535)

              
            

          

        


        
        

          
🔒 HTTP vs. HTTPS (Capa de Aplicación)

          

            

              
                

                  Aspecto
                  HTTP
                  HTTPS
                

              
              
                
Puerto habitual80 / TCP443

                
CifradoSin cifrar (texto legible)Cifrado con TLS

                
AutenticaciónNo verifica al servidorCertificados digitales

                
Seguridad en redTerceros pueden leer o alterar datosEvita lectura y alteración del tráfico

              
            

          

        

      


      
      

        
🌐 Métodos HTTP y Códigos de Estado (Los que pide el profesor)

        

          

            

              
                
MétodoPara qué sirve

              
              
                
GETPide y recupera una página o datos sin modificar nada.

                
POSTEnvía datos en el cuerpo para procesarlos o crear un recurso.

                
DELETESolicita al servidor borrar un recurso concreto.

                
OPTIONSConsulta qué opciones o métodos permite el servidor (CORS).

              
            

          


          

            

              
                
CódigoSignificado

              
              
                
200 OKLa petición se ha atendido correctamente.

                
403 ForbiddenEl servidor entiende la petición, pero prohíbe el acceso por falta de permisos.

                
404 Not FoundEl servidor no ha encontrado el recurso solicitado.
