Tablas Comparativas Clave

Característica TCP UDP
Conexión previa Orientado a conexión (establece conexión antes de enviar). Sin conexión previa.
Fiabilidad y orden Fiable: entrega en orden, usa confirmaciones (acuses de recibo) y retransmite si hay fallos. No fiable: no confirma, no ordena ni retransmite.
Velocidad y uso Ideal para páginas web y transferencia de archivos. Mucho más rápido y ligero; usado en DNS y aplicaciones en tiempo real.
Capa y direccionamiento Capa de Transporte (usa números de puerto). Capa de Transporte (usa números de puerto).
Aspecto HTTP (Sin cifrar) HTTPS (Seguro)
Puerto habitual 80 / TCP 443
Cifrado de datos Envía el contenido en texto legible; un intermediario puede leerlo o alterarlo. Protegido con TLS: cifra la comunicación para evitar que terceros lean o cambien el tráfico.
Identidad del servidor No verifica la identidad del servidor. Verifica la identidad del servidor mediante certificados digitales.
Métodos HTTP (Los que pide el profesor)
GET Pide y recupera una página o datos del servidor sin modificar nada.
POST Envía datos al servidor (en el cuerpo de la petición) para procesarlos o crear un recurso nuevo.
DELETE Solicita al servidor que borre un recurso concreto.
OPTIONS Pregunta al servidor qué opciones o métodos de comunicación permite (se usa también en CORS).
Códigos de Estado HTTP
200 OK Indica que el servidor ha atendido la petición correctamente.
403 Forbidden El servidor entiende la petición, pero prohíbe el acceso por falta de permisos.
404 Not Found El servidor no ha encontrado el recurso que se le ha pedido.
